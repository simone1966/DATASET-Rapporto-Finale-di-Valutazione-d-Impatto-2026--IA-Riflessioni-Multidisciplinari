## Repository Structure
- `OPENSC_2026_FAIR_Dataset_Pipeline.ipynb`: Reproducible Jupyter / Google Colab notebook for loading, verifying anonymization, and generating descriptive tables and figures.
- `CITATION.cff`: Machine-readable citation metadata for GitHub and Zenodo DOI minting.
- `data/01_survey_T0_baseline.csv`: Baseline survey item distributions (`N = 74` respondents, LimeSurvey ID `653721`, items `A1`–`A11`).
- `data/02_survey_T2_post.csv`: Post-intervention survey item distributions (`N = 47` respondents, LimeSurvey ID `164218`, items `A1`–`A13`).
- `data/03_second_ring_surveys.csv`: Harmonized anonymized individual survey records across the three Second Ring cohorts (`es-AR`: 15, `ro`: 29, `ru`: 16; total `N = 60`).
- `data/04_lab_reflections_corpus.csv`: Anonymized corpus of `N = 276` student reflections collected across Workshops 1 to 6 (`REFL_001`–`REFL_276`).
- `data/05_lab_T1_assessments_meta.csv`: Anonymized timestamp and completion metadata for longitudinal workshop assessments (`T1`, `N = 348` records across Labs 1–6).
